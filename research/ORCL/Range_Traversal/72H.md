# 72H: trailing 72 clock hours

Vector: the multi-session swing context just behind today. Method: `BAND_METHOD.md`.

## Bar set
- 5-minute regular-session bars whose timestamps fall within the 72 clock hours ending at the latest bar. Closed time is not padded.
- Report the first and last bar, the number of sessions touched (often 2 to 4, partial at the front edge), and any weekend or holiday gap. On a Monday afternoon the window reaches back to Friday afternoon, so it holds part of Friday plus Monday and nothing for the weekend.
- TTD: recompute when a new session's first bar arrives. Intraday refresh follows the freshness gate in `README.md`.

## Window-specific measures
1. Session slices: range, close and dollar volume for each session inside the window, so the window is read as steps rather than one blob.
2. Gaps between sessions: size and direction of each overnight or weekend gap, and whether later bars filled it. A gap is a discontinuity; do not treat prices across it as continuous traversal.
3. Swing high and low of the window, and which session set each.
4. Bands that persist across sessions: a band with distinct touches in two or more sessions outranks a band with the same touch count in one.
5. Event inside the window: report whether an earnings print, guidance, financing or partnership item (B03 events) sits inside it; show the traversal with and without the event bars.
6. Position of today's range inside the 72H range, passed to `CROSS_WINDOW.md`.

## Output (three lines)
- Range, position, sessions covered, gaps.
- Top persistent band with dollar-volume method and sessions in which it was touched.
- Regime and whether an event dislocation is in the window.

## Window-specific tests
- Monday window spanning a weekend gap.
- Holiday or half-day inside the window.
- Overnight earnings gap: event_dislocation, not balance.
- Band formed entirely in one session versus across sessions.

## Open parameters
- Whether 72H should mean three completed sessions instead of 72 clock hours.
- Minimum number of sessions for a persistent band (v0: 2).
