## Verified behavior and remaining limits

The GitHub GraphQL Projects reference was read on 2026-11-10:
https://docs.github.com/en/graphql/reference/projects

`ProjectV2.items` supports POSITION ascending order.
`updateProjectV2ItemPosition` takes projectId, itemId and optional afterId; null
afterId moves to the top. The adapter rereads state rather than treating a mutation
response as proof of final order.

Coverage includes complete pagination, all requested issue IDs preflighted before

items, fresh native-mode dry-run, repeated full CLI synchronization, sync failure

Position changes are not atomic and cannot provide compare-and-swap. Serialize
all writers. Pre/post reads detect observed drift, not every race. An error stops
further moves, without rolling back earlier successful moves or a concurrent
writer's changes. Read/replan after partial outcomes. A sorted view may display
items differently from native position order.
